# 西游斗牌 Xiyou Joker

局域网多人回合制纸牌游戏：3~6 人用一副扑克牌，以西游记师徒与妖怪为牌面，按「妖怪 → 唐僧 → 三师兄弟 → 妖怪」的环形克制出牌；压不住就收走桌面所有牌作为败牌，最终**败牌最少者通杀获胜**。

## 快速开始

要求 [Node.js](https://nodejs.org/) LTS（20 及以上）。

```bash
npm install
npm start
```

Windows 用户也可直接双击根目录的 `启动游戏.cmd`（首次运行会自动安装依赖）。

启动后终端会打印局域网访问地址（如 `http://192.168.3.166:3000`），同一局域网内的手机 / 电脑用浏览器打开该地址即可加入。房间码为 3 位数字（100-999），创建或输入相同房间码即可进入同一房间。

## 游戏规则（简版）

- **角色牌**：3=沙僧、5=孙悟空、8=八戒、10=唐僧
- **环形克制**：任意妖怪可压唐僧 → 唐僧可压三师兄弟 → 任意师兄弟可压任意妖怪；同组内大压小（妖怪 4<6<7<9<J<Q<K<小王<大王，师兄弟 3<8<5）
- **功能牌**：A=跳过自己本次出牌；2=反转出牌顺序
- **出牌**：轮到自己必须压制当前门槛牌或打出功能牌；既压不住也没有功能牌，则收走桌面全部牌作为败牌
- **补牌**：收牌后全员依次补牌至 5 张，收牌者开启新一轮任意出牌
- **多张组合**：可一次打出 2~4 张同点牌；压制组合必须与门槛张数相等（如 3 张小妖须 3 张更大的同点牌压制）
- **胜负**：摸牌堆耗尽后统计，败牌堆最少者通杀；下一局由通杀者先出

完整规则见 [游戏设计文档.md](游戏设计文档.md)。

## 功能特性

- 房间制联机：3 位数字房间码、自动默认昵称，即开即玩
- 实时对局：Socket.IO 通信，断线自动托管、60 秒内可重连回原座位
- 服务端权威结算：所有游戏逻辑在服务端执行，只向玩家下发其本人手牌，防作弊
- 多张同点组合压制，桌面标注 ×N 门槛张数
- 42 项单元测试全绿 + 浏览器多人端到端验证

## 技术栈

Node.js + Express（静态托管）+ Socket.IO（实时通信）+ 原生 HTML/CSS/JS（零构建）

## 目录结构

```
server.js          进程入口：静态服务、局域网 IP 打印
lib/cards.js       纯函数层：牌定义、克制判定、洗牌
lib/engine.js      规则引擎（无 I/O）：房间状态机、回合流转、结算
net/net.js         Socket.IO 协议层：事件接入、按人定制广播、托管与重连
public/            前端页面（单页应用）
test/              node:test 单元测试
```

## 部署到香橙派（192.168.3.185:3000）

这台板子已经把它当作门户的一个「游戏」模块在跑：systemd 托管、跟着门户的
版本对比页一起升级，出问题会自动重启。

```bash
# 首次
git clone <镜像> ~/Yangfan_WorkSpace/xiyou_joker
cd ~/Yangfan_WorkSpace/xiyou_joker && npm ci --omit=dev
sudo install -m 644 deploy/xiyou-joker.service /etc/systemd/system/
sudo systemctl daemon-reload && sudo systemctl enable --now xiyou-joker.service

# 之后改代码：本机 push 到镜像，页面点「升级」即可
git push mirror main
```

几个和板子相关的约束（换机器部署也会遇到）：

- **`node_modules` 不进版本库**，所以镜像里没有依赖，换机器必须单独跑一次 `npm ci`。
  `package.json` 没变就不用重跑。
- **日志写 `/var/log/xiyou-joker.log`**：这块板子的 journald 收不到应用日志，
  `journalctl -u xiyou-joker` 永远是空的，别在那里找。
- **`Restart=always` 是必需的**：板子上 node 启动有约 7% 概率直接崩
  （V8 deserialization OOM，不是内存不足），不自动重启会永久离线。
- **房间是内存态**，重启服务会把正在进行的牌局清空，升级别挑有人玩的时候。
